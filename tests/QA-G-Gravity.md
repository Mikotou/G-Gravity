## 复跑

在项目目录中执行以下 PowerShell 命令即可完成类型检查、默认测试、打包和离线窗口验收。

```powershell
npm ci
npm run typecheck
npm test
npm run dist:exe
npm run test:desktop
```

在已登录且支持蜂群的官方 `agy` 环境中，以下命令还会实际建立测试会话、创建子成员并收发消息，会使用当前账号额度。

```powershell
$env:AGY_OFFICIAL_SMOKE = '1'
$env:GRAVITY_SWARM_SMOKE = '1'
npm test
$env:GRAVITY_DESKTOP_LIVE = '1'
npm run test:desktop
```
